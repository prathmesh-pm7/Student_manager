# School

A simple **C++ School Management System** project developed as part of my diploma Computer Engineering practice. The project demonstrates the use of **Object-Oriented Programming (OOP)** concepts, functions, and basic record management through a console-based application.

## Project Structure

```text
School/
├── Library.cpp      # Library management module
└── Students.cpp     # Student management module
```

## Features

### Student Management

* Add student records
* Display student information
* Manage student details through a console interface

### Library Management

* Store book information
* Issue and return books
* Track library records
* Manage book availability

## Technologies Used

* **Language:** C++
* **Paradigm:** Object-Oriented Programming (OOP)
* **Compiler:** g++ / MinGW / Visual Studio Code

## How to Run

### Compile

Compile both source files:

```bash
g++ Students.cpp Library.cpp -o School
```

### Run

**Windows**

```bash
School.exe
```

**Linux / macOS**

```bash
./School
```
